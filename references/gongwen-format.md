# 公文规范层

依据分两层。通用层是《党政机关公文处理工作条例》（中办发〔2012〕14 号）、GB/T 9704—2012《党政机关公文格式》、GB/T 15835—2011《出版物上数字用法》。单位层是各单位自己的公文格式规定，颗粒度更细。两者冲突时，以本单位规定为准，这是硬规则，不要拿通用国标去覆盖单位参数。

下面第一节给出一套可直接落进 Word 的企业版参数，取自某企业集团 2013 年公文格式规定的一手材料，不是网络转载的国标版本。换单位要重新取参数，不能照搬。

## 一、版式参数

### 1. 幅面与版面

| 项目 | 规定 |
| --- | --- |
| 纸张 | 国际标准 A4，成品幅面 210 × 297 mm |
| 上边距（天头） | 3.7 cm（37 mm ± 1 mm） |
| 下边距 | 3.5 cm |
| 左边距（订口） | 2.8 cm（28 mm ± 1 mm） |
| 右边距 | 2.6 cm |
| 版心 | 156 × 225 mm |
| 行数字数 | 每面 22 行，每行 28 字，撑满版心；特定情况可适当调整 |
| 行距 | 固定值 28 磅 |
| 段落 | 两端对齐；首行缩进 2 字符；段前 0 行，段后 0 行 |

参数自洽核对：22 行 × 28 磅约 217 mm，28 个三号字约 158 mm，与 156 × 225 mm 的版心基本吻合。三个数凑不上时，先怀疑参数抄错，不要硬套。

### 2. 字体与字号

| 层级 | 字体 | 字号 | 加粗 | 序数样式 |
| --- | --- | --- | --- | --- |
| 主标题 | 方正小标宋简体 | 二号（22 磅） | — | — |
| 一级标题 | 黑体 | 三号（16 磅） | 黑体本身即粗体观感 | 一、；二、；三、…… |
| 二级标题 | 楷体_GB2312 | 三号（16 磅） | 不加粗 | （一）（二） |
| 三级标题 | 仿宋_GB2312 | 三号（16 磅） | 加粗 | 1.；2.；3. |
| 正文 | 仿宋_GB2312 | 三号（16 磅） | 不加粗 | — |
| 页码 | 仿宋_GB2312 | 四号（14 磅） | 不加粗 | — N — |

字号换算：二号 = 22 磅，三号 = 16 磅，四号 = 14 磅。中文写法「楷体国标（GB2312）」「仿宋国标（GB2312）」，对应的 Word 字体名是 `楷体_GB2312` 和 `仿宋_GB2312`，搜字体时用下划线，不要用空格或短横。

三类字形相近但不能互换的字体：仿宋（simfang.ttf）与仿宋_GB2312 不是一款；楷体（simkai.ttf）与楷体_GB2312 不是一款；方正公文小标宋与方正小标宋简体不是一款。

### 3. 西文与数字跟随所在段落的中文字体

英文单词、英文字母、阿拉伯数字，使用它们所在那句话的中文字体，不单独指定西文字体。

逐级落实：正文里的用仿宋_GB2312 三号；一级标题里的用黑体三号；二级标题里的用楷体_GB2312 三号；三级标题里的用仿宋_GB2312 三号；主标题里的用方正小标宋简体二号。

做法是在每级样式的字体对话框里，「中文字体」和「西文字体」两栏都填该级自己的那个字体。只设一个全局西文字体，会让一级标题、二级标题、主标题里的英文和数字全部变成同一种字体，与同句中文对不上，层级感随之消失。

### 4. 允许西文在单词中间换行

对应 Word 段落 → 中文版式 → 勾选「允许西文在单词中间换行」。行末英文单词放不下时直接拆开接排，避免两端对齐把上一行字距拉开、行末留大片空白。

### 5. 页码

格式为「— N —」，两侧各一个一字线（长破折号），中间是阿拉伯数字。

- 是一个长破折号（—，em dash），不是两个连写的「——」，也不是半角减号「-」。
- 数字与破折号之间留一个半角空格。
- 数字必须用可自动更新的页码域，不能手打文本。做法是页脚插入页码域，再在域的前后各输入一个长破折号。
- 字体字号：仿宋_GB2312，四号（14 磅），不加粗。页码域和两侧的破折号一起选中设置，只改数字会让破折号留着默认字体，视觉上粗细不匀。

位置：必须勾选「奇偶页不同」。奇数页页码在右下角，右对齐或右缩进到版心右边缘；偶数页页码在左下角，左对齐。

封面和正文首页都不编页码：封面页不显示页码，正文首页（正文第 1 页）也不显示，从正文第 2 页起显示。

页码数字从正文算起：封面不占页码序列，封面那一节根本不放页码域；正文节把起始页码设成 1。因此正文首页是第 1 页但不显示，正文第二页显示「— 2 —」，第三页「— 3 —」。

必须分节：封面和正文分成两节（封面后插入「分节符（下一页）」）。「首页不同」只对节的第一页生效，不分节时它只能压住封面那一页，正文首页照样出页码。

### 6. 图片与图表

含图片或图表的段落，行距一律改成单倍行距。正文的固定值 28 磅会把超出部分裁掉，图上看着是残的。

数据图表必须用 Word 自带的图表工具生成（插入 → 图表 → 选类型 → 在弹出的数据表里填数据）。不许在其他软件里做好、导出成图片再插入：那样不能改数据、不能改样式、放大就糊，等于把可编辑的结构换成死图。

普通照片、扫描件、示意图不受此限，正常插入即可，但仍须遵守单倍行距。

图表题注用插入题注功能，不要手打编号。

### 7. Word 操作顺序

1. 布局 → 纸张大小 → A4。
2. 布局 → 页边距 → 自定义边距：上 3.7、下 3.5、左 2.8、右 2.6 cm。
3. 逐级改样式（正文、三级标题、二级标题、一级标题、主标题）：字体对话框里「中文字体」和「西文字体」两栏填同一个字体。
4. 段落设置：两端对齐、首行缩进 2 字符、段前 0 行、段后 0 行、行距固定值 28 磅。
5. 段落 → 中文版式 → 勾选「允许西文在单词中间换行」。
6. 封面之后插入「分节符（下一页）」。
7. 页码：勾「奇偶页不同」和「首页不同」；封面节页脚留空；正文节设起始页码 1；奇数页页脚插页码域后右对齐，偶数页页脚插页码域后左对齐；正文首页页脚留空；页码域与破折号统一设仿宋_GB2312 四号。
8. 图片图表：插入后选中所在段落改单倍行距；数据图表用「插入 → 图表」生成。
9. 标点：半角逗号、句号、引号、括号逐个改成中文全角。Word 没有可靠的一键中英标点互转功能，全角半角转换会把数字和字母一起转，这一步只能人工或逐项查找替换。
10. 成品核对：每面 22 行、每行 28 字；封面和正文首页无页码；正文第二页是「— 2 —」；奇偶页位置正确；页码字体为仿宋_GB2312 四号；每个含图段落为单倍行距；数据图表是 Word 原生对象（点一下能出现图表工具栏和数据源）。

### 8. 字体可用性

改公文前先确认本机装了仿宋_GB2312、楷体_GB2312、方正小标宋简体三款字体。检测必须两个注册表位置、两个文件目录都查：HKCU 与 HKLM 的 `SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts`，以及 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` 与 `C:\Windows\Fonts`。只查 HKLM 会漏掉用户级安装的字体，得出「没装」的错误结论。

交付时可在 Word 里勾选「将字体嵌入文件」（文件 → 选项 → 保存），换机器打开不掉字体。

## 二、十五种法定文种，用错就等于发错

| 文种 | 用途 | 行文方向 |
| --- | --- | --- |
| 决议 | 会议讨论通过的重大决策事项 | 下行 |
| 决定 | 对重要事项作出决策和部署、奖惩单位人员、变更或撤销下级不适当的决定 | 下行 |
| 命令（令） | 公布行政法规规章、宣布重大强制性措施、批准授予晋升衔级、嘉奖 | 下行 |
| 公报 | 公布重要决定或重大事项 | 公开发布 |
| 公告 | 向国内外宣布重要事项或法定事项 | 公开发布 |
| 通告 | 在一定范围内公布应当遵守或周知的事项 | 公开发布 |
| 意见 | 对重要问题提出见解和处理办法 | 上/下/平行均可 |
| 通知 | 发布传达要求下级执行和有关单位周知的事项，批转转发公文，任免人员 | 下行 |
| 通报 | 表彰先进、批评错误、传达重要精神、告知重要情况 | 下行 |
| 报告 | 向上级汇报工作、反映情况、回复上级询问 | 上行 |
| 请示 | 向上级请求指示、批准 | 上行 |
| 批复 | 答复下级请示事项 | 下行 |
| 议案 | 政府按法律程序向同级人大或常委会提请审议事项 | 平行（特定） |
| 函 | 不相隶属机关之间商洽工作、询问答复问题、请求批准和答复审批 | 平行 |
| 纪要 | 记载会议主要情况和议定事项 | 下行或知照 |

### 最常混的五组

**请示 / 报告。** 请示是要批复的，必须一文一事，结尾写「妥否，请批示」或「请予批复」。报告是让上级知道的，不要批复，结尾写「以上报告，请审阅」。请示里夹带报告事项、报告里夹带请示事项，都算违规。

**通知 / 通报。** 通知布置工作、传达要求；通报是表彰、批评、告情况。把处分决定写成「通知」是常见的错。

**函 / 请示。** 平级或不相隶属的机关之间用函。向平级单位「请示」等于把对方当上级。

**意见 / 决定。** 意见提见解和办法，可以商量；决定是已经定了的安排，必须执行。

**纪要 / 会议记录。** 纪要只写议定事项和主要精神，不写谁发了什么言、谁有不同意见。会议记录不是法定文种，不能当文件发。

## 三、行文规则（条例第十三条至十九条）

- 上行文原则上主送一个上级机关，需要时抄送相关上级和同级机关，**不抄送下级机关**。
- 请示**一文一事**，不得多头主送。多头主送会导致谁都不批。
- 除上级负责人直接交办外，不以本机关名义向上级机关负责人个人报送公文。
- 受双重领导的机关向上级行文，主送一个，必要时抄送另一个。
- 向下级的重要行文，同时抄送发文机关的直接上级。
- 同级党政机关、党政机关与其他同级机关必要时可联合行文；**属于各自职权范围内的工作不得联合行文**。
- 涉及其他部门职权的事项，须与有关部门协商会签后再发。
- 部门内设机构除办公厅（室）外，不得对外正式行文。

写公文时先过这四条：主送给谁、要不要抄送、是否多头、是否越权。

## 四、结构要素

版头部分：份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人（**上行文必须标注签发人**）。

主体部分：

1. **标题**：发文机关 + 事由 + 文种。事由不能省，「关于……的通知」。标题里除法规规章名称外加书名号是错的。
2. **主送机关**：顶格，名称后加冒号。多个主送机关用顿号并列，最后加「各」的统称放前面。
3. **正文**：三段式最稳。缘由（依据、目的、背景）—事项（做什么、谁做、怎么做、什么时候完成）—要求（执行口径、反馈时限、联系方式）。
4. **附件说明**：正文下空一行，左空二字，「附件：1.×××」。附件名不加书名号，末尾不加标点。
5. **发文机关署名**：用全称或规范化简称。
6. **成文日期**：用阿拉伯数字标全年月日，写「2026年11月10日」。
7. **印章**：署名和日期之间压印。
8. **附注**：需要说明的事项，如联系人、电话、「此件公开发布」。

版记部分：抄送机关、印发机关和印发日期、页码。

### 层次序数

四层，顺序不能跳：

```
一、
（一）
1.
（1）
```

「一、」后面用顿号，「（一）」后面**不加**任何标点，「1.」后面用下脚点不用顿号。第三层以后不是必须使用，能够用自然段表述清楚的，不另行分层。

### 正文内部顺序

机关内部行文常按「依据—现状—问题—措施—要求」走。措施部分要能落成动作：谁、做什么、什么时间、做到什么程度、不做到怎么办。只有「加强」「提升」「推进」没有主语的句子，等于没有措施。

## 五、数字用法

用阿拉伯数字：

- 计量、统计、编号、百分比、比例、分数
- 公历世纪、年代、年月日、时刻
- 文件编号、证件号码

用汉字：

- 概数和约数：「三五个」「十几个」「七八十人」
- 成语和惯用语：「一心一意」「三令五申」「一方面」「三级」
- 农历和清代以前的历史纪年
- 星期几

硬规则：

- 年份**不能简写**，「2026 年」不能写成「26 年」。
- 成文日期用阿拉伯数字，不用「二〇二六年」这种汉字写法（版头印刷体除外）。
- 相邻数字并列表示概数用汉字，「七八十人」不写「70、80 人」。
- 百分数范围写「20%～30%」，不写「20～30%」。
- 一个数字里不用千分位空格混搭，全文统一。

## 六、标点

- 「一、」后用顿号，「（一）」后不用标点。
- 并列的引号、书名号之间不用顿号。
- 引用公文先引标题后引发文字号：「《关于××工作的通知》（×政发〔2026〕15 号）」。
- 标题末尾不加句号。正文里小标题末尾可以不加标点。
- 公文正文里破折号极少用，能改写就改写；冒号在「如下：」「现将有关事项通知如下：」的位置是规范用法，不要当 AI 味删掉。
- 标点一律用中文全角：逗号「，」、顿号「、」、分号「；」、冒号「：」、句号「。」、引号「“”」「‘’」、括号「（）」、书名号「《》」、六角括号「〔〕」、破折号「——」、省略号「……」、间隔号「·」。发文字号里的六角括号不能写成半角方括号。
- 数字内部的小数点、千分位逗号、百分号、单位符号属于数值本身，仍按半角处理。

## 七、固定用语

开头：

- 「为……，根据……，现就……通知如下：」
- 「按照……要求，现将……印发给你们，请认真贯彻执行。」
- 「现将……转发给你们，请结合实际抓好落实。」

结尾：

| 文种 | 结语 |
| --- | --- |
| 通知 | 特此通知 |
| 通报 | 特此通报 |
| 函（发函） | 特此函达 |
| 函（复函） | 特此函复 |
| 请示 | 妥否，请批示 / 请予批复 |
| 报告 | 以上报告，请审阅 |
| 批复 | 此复 |
| 印发类 | 请遵照执行 / 请认真贯彻执行 |

结语与文种不匹配会造成效力误判：报告的结语写「请批示」，上级会按请示处理；请示的结语写「请审阅」，事项无法进入批复程序。

## 八、十二个高频硬错

1. 文种混用：该请示的写成报告，该发函的写成通知。
2. 请示一文多事，或请示里夹带汇报内容。
3. 多头主送，尤其是同时报党委和政府又都要求批复。
4. 越级行文且未抄送被越过的一级。
5. 标题缺事由，只写「××局通知」。
6. 成文日期与签发日期不一致，或日期写作「2026.11.10」。
7. 附件说明列了三件，实际只附两件。
8. 层次序数跳级，出现「（一）」下面直接接「（1）」。
9. 数字写法混用，同一页里「5 个」和「五个」并存。
10. 称谓不统一，前面「我局」后面「本单位」。
11. 简称未定义，第一次出现就用「市职教中心」，没写全称。
12. 时间指代模糊，「今年」「近期」「日前」出现在正式文件里。正式文件写具体年月日。

## 九、版式覆盖边界

以上参数覆盖幅面、字体字号、行数字数、段落缩进、页码、图表。版头、主体、版记各要素的具体位置和字体（份号、密级、发文机关标志、发文字号的字号与位置，印章的压印位置），需另取本单位规定，不在本节范围。

这套参数是企业内部规定，不是国家标准，换单位不能照搬。其中「2013 年」这一版本是否已被新文件替代，未经核实，落到具体单位时应确认现行版本。
